# DGE 요구사항과 검토

개인이 매일 쓰는 할 일 · 일정 관리 데스크탑 앱(macOS 26+, SwiftUI · SwiftData).
"빨리 적고, 오늘 할 일을 놓치지 않고, 일정과 할 일을 한 화면에서 본다"를 기준으로 요구사항을 뽑고, 들일 품 대비 쓸모로 걸렀다.

## 1. 요구사항

### 할 일
| 요구사항 | 상태 | 어디에 |
|---|---|---|
| 오늘(기한 지남 포함) · 예정 · 완료 · 목록 화면 | 완료 | `Features/*`, `TaskListScreen` |
| 우선순위(없음 · 낮음 · 보통 · 높음) | 완료 | `Priority`, 상세 패널, 우클릭, `⌃0–3` |
| 태그 · 태그별 화면 · 사이드바 태그 목록 | 완료 | `TagView`, `TagEditor` |
| 체크리스트(하위 단계) | 완료 | `ChecklistEditor`, 줄에 `1/3` 표시 |
| 반복(매일 · 평일 · 매주 · 격주 · 매월 · 매년) | 완료 | 끝내면 다음 차례를 새로 만든다 (`TaskStore.setCompleted`) |
| 알림(시각) · 알림에서 바로 완료 / 10분 뒤 | 완료 | `NotificationService` |
| 미루기(오늘로 · 내일 · 다음 주 월요일 · 날짜 지우기) | 완료 | 마우스 올림 버튼, 우클릭, `⌘T` `⇧⌘T` `⌥⌘T` |
| 여러 개 골라 한 번에 처리 | 완료 | `⌘`/`⇧` 클릭 + 우클릭 · 메뉴 명령 |
| 삭제 되돌리기 | 완료 | 삭제 뒤 5초간 "실행 취소" 안내 |
| 목록 만들기 · 이름 바꾸기 · 지우기 · 순서 바꾸기 | 완료 | 사이드바. 지워도 할 일은 남는다 |

### 빠른 입력
| 요구사항 | 상태 | 어디에 |
|---|---|---|
| 한 줄에서 날짜 · 시각 · #태그 · !우선순위 · @목록 · 반복 알아듣기 | 완료 | `QuickAddParser` (입력 중 미리보기) |
| 어디서나 여는 빠른 입력 창(전역 단축키) | 완료 | `QuickEntry`, 기본 `⌃⌥Space` |
| 검색 · 명령 창 | 완료 | `⌘K` / `⌘F`, 못 찾으면 그대로 새 할 일 |
| 메뉴 막대 · 미니 창에서 보고 · 끝내고 · 적기 | 완료 | `MenuBarView`, `MiniWindowView` |

### 일정 · 캘린더
| 요구사항 | 상태 | 어디에 |
|---|---|---|
| 월 · 주 · 일 보기 | 완료 | `CalendarBoard`, `TimeGridView` |
| 할 일을 캘린더에 함께 표시(끌 수 있음) | 완료 | 시각 있는 할 일은 시간 격자에, 없으면 '종일' 줄에 |
| 끌어서 날짜 · 시각 옮기기 | 완료 | 할 일을 시각에 놓으면 그 시각 알림 |
| 하루 종일 · 반복 · 알림(몇 분 전) | 완료 | `EventDetailPanel` |
| macOS 캘린더(iCloud · Google 등) 일정 보기 | 완료 | 읽기 전용, 설정에서 켠다 (`SystemCalendar`) |
| 한 주의 시작 요일 | 완료 | 설정 › 캘린더 |

### 메모
| 요구사항 | 상태 | 어디에 |
|---|---|---|
| 할 일과 별개인 메모(목록 + 편집기, 검색, 고정) | 완료 | `NotesView`, `Note`, `⌘6` |
| 데일리 스크럼 메모: 어제 한 일 · 오늘 할 일 · 오늘 일정 · 막힌 점을 할 일 기록에서 채움 | 완료 | `NoteStore.scrumBody`, 목록 하나로 좁히기 · 다시 채우기 |
| 스크럼 날짜 고르기: 오늘 것 / 다음 근무일 것 미리 준비 / 다른 날 | 완료 | `ScrumDayPicker`, 메모 안에서 날짜 옮기기 |
| 메모의 줄을 할 일로 만들기(날짜 · 태그 등 인식) | 완료 | 편집기 "할 일로 만들기" (`⇧⌘↩`) |
| 메모도 ⌘K 검색 · 백업에 포함 | 완료 | `CommandPalette`, `BackupFile.notes` |

| 로그인할 때 열기 · Dock 배지 · 메뉴 막대 개수 | 완료 | `LoginItem`, `AppServices` |
| 라이트 / 다크 / 시스템, 테마 · 글자 크기 | 완료 | `DGEAppearance` |

| 백업 내보내기 · 가져오기(JSON, 합치기) | 완료 | 설정 › 데이터 (`BackupService`) |

## 2. 검토하며 정한 것

- **반복 할 일은 "끝내면 다음 차례 생성"** 으로 한다. 반복 규칙은 새 할 일이 이어받고, 끝낸 것은 기록으로 남는다. 밀린 반복을 끝내면 오늘 이후 첫 차례로 건너뛴다.
- **반복 일정은 시작 날짜 기준으로만 계산**한다. 여러 날에 걸친 반복 일정은 첫날에만 보인다. 차례 하나만 따로 고치는 기능(예외)은 넣지 않았다.
- **알림은 바뀔 때마다 전부 다시 예약**한다. 저장이 일어나면(`ModelContext.didSave`) 0.4초 모아서 한 번. 가까운 60개까지만 넣는다.
- **실행 취소는 시스템 UndoManager 대신 스냅샷**으로 했다. 글 입력의 되돌리기와 섞여 엉뚱하게 되돌아가는 것을 피하려고.
- **메뉴 명령(⌘⌫ 등)은 목록에 포커스가 있을 때만** 켜진다. 글을 쓰다가 ⌘⌫로 할 일이 지워지지 않게.
- **목록 선택은 시스템 선택을 그대로** 쓴다. 회색으로 직접 그리면 끌어서 순서 바꾸기가 깨졌다.
- **macOS 캘린더는 읽기만** 한다. 쓰기까지 하면 두 곳의 일정이 어긋날 때 풀기 어렵다.
- **스크럼의 "어제"는 지난 근무일**이다. 월요일이면 금요일부터 주말까지 끝낸 것을 모은다. 같은 날 스크럼 메모는 하나만 만든다.
- **메모는 서식 없는 글**로 둔다. `- ` 글머리표 정도만 쓰고, 마크다운 렌더링은 넣지 않았다.
- 모델은 모든 새 필드에 기본값을 두어 **가벼운 마이그레이션**으로 넘어간다. 실제 저장소 사본으로 확인함(할 일 · 목록 그대로, 새 필드 쓰기 가능).

## 3. 뒤로 미룬 것

- 반복 일정의 차례 하나만 고치기 / 반복 종료일
- 시간 격자에서 일정 길이를 끌어서 늘이기
- macOS 캘린더에 쓰기, 캘린더별 보이기 · 숨기기
- iCloud 동기화(여러 Mac), iPhone 앱
- 단축어(App Intents) · Spotlight 동작
- 할 일 목록에서 사이드바로 끌어 옮기기 (지금은 우클릭 › 목록으로 이동)
